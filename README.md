# Lidarr.Plugin.YtDlp

Lidarr plugin: YouTube downloader + indexer backed by an existing yt-dlp installation, with SponsorBlock filtering.

- `docs/` — research notes and implementation plans
- `Lidarr.Plugin.YtDlp/` — plugin source (net8.0, C# 12)
- `Lidarr.Plugin.YtDlp.Tests/` — NUnit 3 + NSubstitute tests
- `.gitlab-ci.yml` — build + tests on push (dotnet sdk 8.0)
